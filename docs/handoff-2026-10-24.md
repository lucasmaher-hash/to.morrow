# to.morrow changes · 24 October 2026

Requested and implemented:

- Archive shows the number of retained completed tasks in the current workspace, including tasks completed today. Deleted records are not counted.
- Editing a Live note keeps the same task and Live Activity. Reconciliation now treats stale and pending cards as ongoing, serializes updates/removals, and dismisses duplicate cards on every pass. The pre-fix regression reproduced two cards after editing stale content; the same test now passes.
- Long-press task menu offers **Move to Workspace**, with a checkmark on the current workspace. Moving preserves the task ID, date, importance and photos, places it in the destination list, and supports Undo. VoiceOver exposes workspace moves too.
- Completing a Live note puts it in Today’s completed list in its original workspace, then archives it at midnight. Uncompleting returns it to Today without making it Live again. The Lock Screen intent explicitly dismisses its task’s card even on a background launch without a visible scene. Existing archived Live records remain readable.
- Reordering waits for the spring’s actual completion rather than a 0.30-second timer. The floating row returns to its normal scale/shadow before an animation-free handoff to the saved order. Completion callbacks are scoped to the drag session.

Also disabled the existing `-wipeAll YES` argument in the shared Xcode launch scheme. It was enabled before this work. No user tasks were wiped.
