# Native Mac 1.0 screenshots — 24 November 2026

These six **2880 × 1800, RGB/sRGB, lossless PNGs** are the saved screenshot set
in the native macOS 1.0 App Store Connect draft, verified after reload.

Order follows filenames 01–06: moving tasks, Live panel, workspace picker,
theme settings, menu-bar popover, task menu.

Lucas captured these from an isolated preview with fake tasks. Exact pixel
cleanup removes system/desktop clutter. The menu-bar popover retains a black
native menu bar to show its origin. The task-menu shot removes traffic lights
and its measured 64px title-bar offset so its app header aligns with fullscreen
captures. A single uniform resize and restrained unsharp mask preserve crisp
text; the source display profile is converted to sRGB. No UI or text is generated.

The older JPG files in the parent folder are retained as history. They were
removed from this Mac version's gallery and remain in Apple's Asset Library.
No iOS screenshots, release settings, or review submission were changed.
